# 符文都市：谐振 0.7.0

导入 `符文都市谐振-正式版-0.7.0.png` 到 SillyTavern，并导入卡内世界书。需要酒馆助手与卡内MVU脚本；在设置中配置正文及手机变量API。

建档的“预置角色库”自动读取171名角色名录，选择后读取完整资料。角色资料、地图和前端脚本使用固定GitHub提交的公开链接，卡包不内嵌这些大文件。角色调度默认开启，主要6人、次要3人。

更新既有聊天时，请导入新卡的世界书，保留原消息变量，不用初始值覆盖旧存档。

资源清单与SHA-256： [remote-release.json](remote-release.json)。当前版本所有资源均已远端下载核对；未进行真实模型生成或界面外观验收。
