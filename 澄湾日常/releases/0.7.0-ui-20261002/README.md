# 符文都市：谐振 · 前端更新 2026-10-02

角色卡版本仍为 0.7.0。本次更新手机通讯录、群聊邀约、朋友圈与微澜，以及次要角色档案。

联系人资料与群聊管理改为独立页面；邀约支持搜索、多选联系人与填写建群名称，一次提交整批邀请，由角色确认后入群。删除邀约快捷文案与联系人个性签名展示。修复群聊设置定位、好友申请对象与状态、删除联系人后的操作、评论草稿及搜索筛选的异步覆盖。次要角色的导航保持可见，人物和 tab 分别记忆滚动位置；修复手机间距被覆盖和启停期间升格操作的问题。暗色样式保留组件选择器，避免全页字体被意外加粗。

[下载更新后的正式卡](符文都市谐振-正式版-手机与档案更新20261002.png)。卡包只调整三个项目脚本的加载入口；世界书、头像、变量初始值及其他卡片内容与原正式版一致。更新既有卡时替换角色卡或这三个加载脚本即可，不要初始化或覆盖旧聊天变量，也不需要重复导入世界书。

新版每次启动脚本时通过固定的 [最新版入口](https://raw.githubusercontent.com/kuozhou1-stack/sillytavern/master/%E6%BE%84%E6%B9%BE%E6%97%A5%E5%B8%B8/frontend-current.json) 获取已发布构建，再使用固定提交的 CDN 链接加载。此入口更新后，重新加载角色卡脚本或重新打开酒馆即可读取新版；已经打开的前端不会在游玩中自动替换代码。旧卡内固定提交的三条 import 链接须更新一次。

仅更换脚本时可参考 [前端加载脚本.json](前端加载脚本.json)，按相同 id 替换 content。需要酒馆助手与 MVU；变量 API 的原配置继续使用。

验证：204 项回归测试、项目类型检查与生产构建通过。已检查实际加载组件的联系人和群聊入口、多人邀请提交，以及 390 / 690 / 860 像素下的次要角色导航与独立滚动。邀请事务的单次请求、失败重试与防止重复建群已通过隔离测试；角色是否接受仍由模型回复决定。远端下载字节与 SHA-256 核对见本地发布记录。
